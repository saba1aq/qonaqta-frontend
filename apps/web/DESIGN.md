# Design — Qonaqta (гостевой веб, qonaqta.kz)

<!-- impeccable:design-schema 1 -->

Визуальный мир гостевого сайта. Партнёрская панель и хаб суперадмина сюда НЕ входят — у них свой служебный вид.

## Мир: «Ризо-гид»

Qonaqta — рукопечатный ризограф-гид Алматы по лучшим столам. Забронировать = вырвать страницу из выпуска. Осознанный отказ от стандарта категории (белая фото-сетка со звёздами-рейтинга, тёплый крем, чипсы). Ощущение — печатный городской зин: кураторский, со вкусом, человечный; бронь при этом в два тапа.

Мир выбран пользователем как альтернатива назначенному дайсом «Табло» (то читалось как AI dark-dashboard). Seed направления: 6426601c.

## Палитра

Печать в несколько красок по тёплой крафт-бумаге. Краски **множатся** на пересечении (mix-blend-mode: multiply), давая третий цвет.

| Роль | Значение | Применение |
|---|---|---|
| paper | `#f2e9d7` | основной фон (светлая крафт-бумага, НЕ тусклая) |
| paper-3 | `#f8f1e3` | поверхность карточек/панелей (чуть светлее фона) |
| paper-2 | `#eaddc4` | приглушённая бумага (разделители, вложенные зоны) |
| ink | `#211d17` | тёплый чёрный — весь текст, обводки, жёсткие тени |
| ink-soft | `#5b5347` | вторичный текст, подписи |
| pink | `#f2315d` | ризо-краска: акцент, выбранное, «место недели», основной action |
| blue | `#2331b4` | ризо-краска: рубрики/кухни, второй дуотон, вторичный action |
| sun | `#f4b71a` | ризо-краска: подсветка «сегодня», третий дуотон, флаги |

Правила цвета: стратегия — **Full palette** (три именованные краски + бумага + чернила), что уместно для Persuade-поверхности. Свет — светлая бумага (сценарий: человек вечером выбирает, куда пойти, с телефона; бумажный гид должен читаться и в помещении, и на улице). Тёмных тем нет.

Зерно бумаги: `radial-gradient(rgba(33,29,23,.05) 1px, transparent 1.3px)` при `background-size:4px 4px`. Никакого затемняющего multiply-wash поверх бумаги — он гасит яркость.

## Шрифты

| Роль | Шрифт | Замечание |
|---|---|---|
| Дисплей (заголовки, названия, крупные цифры) | **Unbounded** 600–800 | кириллица есть; тесный трекинг `-.03…-.045em`, line-height ~.88 |
| Штампы / фолио / рубрики / метки | **Oswald** 500–700 | uppercase, tracking `.1–.16em` |
| Текст / UI / чтение | **Golos Text** 400–600 | кириллица-нативный нейтральный гротеск; measure 60–72ch |

Запрещено: Bricolage Grotesque, Inter/Geist-as-display и прочие «дефолтные дисплеи» — и отдельно любой дисплей-шрифт БЕЗ кириллицы (молча падает в системный на русском тексте).

## Материалы и компоненты

- **Cut-paper карточка** — поверхность `paper-3`, обводка `2px solid ink`, **жёсткая офсетная тень цвета краски** (`box-shadow: 7px 7px 0 ink`, на ховере `11px 11px 0 pink` + сдвиг), лёгкий поворот `±.5deg`, выпрямляется на ховере. Это родной приём мира, НЕ «мягкая тень».
- **Фото — натуральные.** Реальные снимки заведений НЕ тонируем (без grayscale/дуотона): гость должен видеть настоящее место. Мир держится рамкой (cut-paper + офсет-тень), типографикой и спот-акцентами. Спот-краска на карточке — тонкая горизонтальная **лента-краска** (`h-1.5`, розовый/синий/жёлтый по чередованию) между фото и текстом, не поверх фото. Спот-цвет как placeholder показывается только когда фото нет.
- **Штамп статуса** — Oswald uppercase, плашка `ink`/цвет краски, поворот `±3–8deg` («резиновый штамп»). «СВОБОДНО», «ЛИСТ ОЖИД.», «ЧЕРНОВИК».
- **Смещение регистра (misregister)** — у крупного акцент-слова дубль в другой краске со сдвигом `translate(3–4px,3px)` + `mix-blend-mode:multiply, opacity ~.4`; сильнее на ховере.
- **Чипы / слоты** — обводка `1.5–2px ink`, Oswald; выбранный — заливка `pink`, текст `paper-3`. Недоступный — `opacity .32` + strike.
- **Кнопка (primary)** — заливка `ink`, текст `paper-3`, жёсткая офсет-тень краски; на ховере сдвиг `-2px,-2px` и рост тени. Вторичная — прозрачная, обводка `2px ink`, тень синяя.
- **Отрывной талон** — `border: 2px dashed ink`, два «прокола» по бокам (круги цвета фона), офсет-тень синяя; штамп статуса.
- **Масткед** — тёмная плашка `ink`, лого `Unbounded` (`Q` — sun) слева, навигация справа, нижняя граница `3px solid pink`. Без фолио-подписи. Никаких фейковых «номеров выпуска» и порядковых «№NN» на карточках — не выдумываем несуществующее издание/рейтинг.

## Движение

Один авторский момент: при загрузке ink-слои «оседают в регистр» — контент появляется `settle` (translateY 10px→0, opacity, exp-ease-out), со ступенчатой задержкой на первом экране. Мелкая моторика: сдвиг/поворот cut-paper на ховере, смещение краски. `prefers-reduced-motion` → без анимаций, misregister статичен. Никаких разбросанных одинаковых ховеров и не по одному входу на каждой секции.

## Лейаут

Полностью **адаптивный** (mobile-first, но красивый и на десктопе). Никаких телефон-в-рамке / max-w-480. Контент-контейнер `max-width ~1140px`, поля `clamp(18px,4vw,44px)`. Сетка каталога 3→2→1 колонки. Разворот ресторана и форма брони — 2 колонки на десктопе, 1 на мобайле. Ритм: над заголовком больше воздуха, чем под ним.

## Запреты (сверх craft-floor)

- Мягкие нейтральные тени вместо жёстких офсет-теней краски (кроме отрывного талона — там своя логика).
- Цветное свечение (glow) на любом фоне — эмфазис через вес/размер/краску, не через halo.
- Дисплей-шрифт без кириллицы.
- Тёмная тема «по категории».
- Стоковые shadcn-компоненты в дефолтном виде внутри мира — перекрашиваются токенами и приёмами мира.
