# Референс: meet.eat — Table reservation & bill splitting app

Источник: https://www.behance.net/gallery/243058097/Table-reservation-bill-splitting-app
Автор: Anastasiya Shapavalava (Tbilisi, Georgia), опубликовано 29.01.2026.
Инструменты: Figma, FigJam, Photoshop, ChatGPT. iOS-приложение: поиск ресторанов, бронь столов, сплит счёта.

Это эталон того, к чему стремится гостевой Qonaqta по ощущению: чисто, дорого, спокойно, один пастельный акцент.

---

## 1. Палитра (точные хексы из секции Design System)

| Токен | Hex | Роль |
|---|---|---|
| Белый | `#FEFEFE` | Поверхности, карточки, кнопки на тёмном (есть вариант 10% opacity для glass-чипов на фото) |
| Светло-серый | `#F3F3F3` | Фон страницы/секций, второстепенные плитки |
| Лиловый основной | `#EEC0FF` | ЕДИНСТВЕННЫЙ акцент: тайм-слоты, выбранные даты, чипы, «More», иконки-кружки |
| Лиловый бледный | `#F9E7FF` | Тихая версия акцента: фоны, hover, второстепенные выделения |
| Почти чёрный | `#1C1C1C` | Текст, primary-кнопки, тёмные экраны (варианты 20% и 8% opacity для оверлеев/скримов) |
| Тёмная поверхность | `#232323` | Карточки на тёмных экранах |

**Механика цвета — главное, что нужно забрать:**
- Нейтральная база (белый + светло-серый + почти чёрный) и **один** пастельный акцент в **двух тонах** (насыщенный `#EEC0FF` + бледный `#F9E7FF`). Больше цветов нет вообще.
- Акцент никогда не кричит: это пастель, ~30% насыщенности, работает пятнами (чип, кружок, дата), а не заливками секций.
- Красный/зелёный/жёлтый статусов в UI нет — статусы решаются текстом и иконкой («Waiting for confirmation ⏳» на нейтральном чипе).
- Весь «цвет» в интерфейсе дают ФОТО ресторанов. UI вокруг них — почти монохром.

## 2. Типографика

| Роль | Шрифт | Начертание |
|---|---|---|
| Display (заголовки, названия ресторанов, цифры календаря) | **Clash Display** | semi-bold |
| Body/UI | **SF Pro** | medium / regular |

- Названия ресторанов набраны Clash Display semi-bold даже внутри мелких карточек — это главный узнаваемый элемент.
- Заголовки секций кейса — тот же гротеск, очень крупно, tracking плотный, часто как полупрозрачный «водяной знак» позади мокапов (Explore / Book / Connect / Split).
- Мелкие подписи (чипы, метаданные) — SF Pro regular, размер ~11–13, без капса-леттерспейсинга.
- Кириллический аналог Clash Display по духу: Unbounded слишком декоративный; ближе — Suisse/Golos-семейство жирных гротесков. (У нас display = Unbounded — оставляем, но вес брать 600–700, не 800.)

## 3. Форма и материалы

- **Радиусы огромные и последовательные**: карточки ~24–28px, кнопки и чипы — full pill, экранные модалки ~32px сверху. Ни одного острого угла.
- **Теней почти нет** — иерархия делается цветом поверхности (белое на сером, `#232323` на `#1C1C1C`) и воздухом. Если тень есть — мягкая, едва заметная.
- **Рамок нет.** Разделение — цветом фона и отступами.
- **Glass-эффект** только поверх фото: полупрозрачные тёмные чипы (`#1C1C1C` 20%) или светлые (`#FEFEFE` 10%) с blur, белый текст.
- Много воздуха: паддинги в карточках ~14–16px, между секциями крупные разрывы.

## 4. Карточка ресторана (анатомия — как в Explore)

Референсная карточка это ФОТО-первая карточка, не «фото сверху + текст снизу»:

1. **Всё поле карточки — фотография** интерьера/еды (натуральная, без дуотона), скругление ~24px.
2. **Название ресторана наложено на фото** сверху слева, белым Clash Display semi-bold, крупно (Unfound Door, Reserve).
3. **Сердечко (избранное)** — сверху справа, белая иконка.
4. **Нижняя кромка фото — ряд glass-чипов** с метаданными: кухни (`European`, `Georgian`), часы (`08:00–14:00`, `18:00–00:00`), чек (`50–70€`), рейтинг (`4.7`). Тёмные полупрозрачные pill, белый текст, ~11px.
5. Лёгкий тёмный градиент-скрим сверху и снизу фото, чтобы текст читался.

Вторичная карточка (списки, брони): маленькое фото слева или фоном, название Clash Display, под ним адрес серым, статус-чип, снизу строка из чипов `дата | время | кол-во гостей`.

## 5. Компоненты

- **Primary button**: full-pill, `#1C1C1C`, белый текст, высота ~52. Одна на экран.
- **Secondary button**: белый pill, тёмный текст, рядом кружок-иконка со стрелкой ↗.
- **Тайм-слоты**: pill-чипы `#EEC0FF` с тёмным текстом (`20:00`, `20:30`, `21:30`) — выбранный темнее/обводка. Это самое заметное применение акцента.
- **Календарь**: обычные цифры — серые; доступные/выбранные дни — лиловые круги разной насыщенности (#F9E7FF → #EEC0FF).
- **Tabs / сегменты**: pill-переключатели (Overview · Opening hours · Reviews; Pending · Upcoming · History), активный — инвертирован (тёмный на светлом экране, белый на тёмном).
- **Фильтры-чипы**: белые/серые pill с текстом, без иконок, в горизонтальный скролл.
- **Поиск**: full-pill поле «What are we booking today?» с лупой слева и кнопкой фильтров справа.
- **Bottom nav**: 5 пунктов (explore, friends, bookings, favourites, profile), иконка + мелкая подпись, логотип «.m» как первый пункт.
- **Rating block**: гигантская цифра `4.9` Clash Display + подпись Excellent + мини-бары распределения; отзывы — карточки с чипами фактов (`Breakfast 40–50€ per person`, `Great service`).
- **Модалки** (Create a list): выезжают снизу, радиус ~32 сверху, на тёмном экране CTA — белая кнопка.

## 6. Тёмные экраны

Социальная часть (Friends, Bookings, Lists, Groups) — на тёмном: фон `#1C1C1C`, карточки `#232323`, текст белый, акцент тот же лиловый. Светлые и тёмные экраны сосуществуют в одном приложении, палитра не меняется — меняется только база.

## 7. Подача кейса (бенто-стиль, полезно для лендинга)

- Вся история собрана из **бенто-карточек** трёх видов: белая `#FEFEFE`, тёмная `#1C1C1C`, лиловая `#EEC0FF`/`#F9E7FF` — на светло-сером фоне `#F3F3F3`, радиус ~28px.
- Чередование цветов карточек создаёт ритм без единой лишней краски: Research (тёмная) → Wireframing (белая) → UI design (лиловая) → Testing (тёмная).
- Фичи подаются так же: одна большая лиловая карточка с телефоном в руке + 3–4 маленьких текстовых карточки вокруг (Discover places by mood / Browse real photos / Check up-to-date menus / Filter by preferences).
- Крупные заголовки-«водяные знаки» позади мокапов задают навигацию по разделам.
- Фото-фоны секций — тёмные, атмосферные (стол, бокалы), поверх — белые карточки с контентом.

## 8. Что забрать в Qonaqta (маппинг)

| meet.eat | Qonaqta (гостевой web) |
|---|---|
| База `#FEFEFE`/`#F3F3F3`/`#1C1C1C` | Уже так: `--color-paper #ffffff`, `--color-paper-2 #f1f1f0`, `--color-ink #211d17` |
| Один пастельный акцент в 2 тонах | Наш `--color-soft` — оставить ровно один акцент; при желании добавить бледный тон `--color-soft-2` для hover/фонов |
| Названия ресторанов display-шрифтом | Уже так (Unbounded), вес держать 600–700 |
| Фото-первые карточки, имя поверх фото, glass-чипы метаданных | Кандидат на редизайн BranchCard: фото на всю карточку + скрим + название поверх + чипы (кухня, адрес/рейтинг) по нижней кромке |
| Full-pill кнопки/чипы, радиусы 24–28, без рамок и теней | Противоположно текущему «Ризо-гид» (radius 0, border-2). Если двигаться к meet.eat — это осознанная смена мира, а не точечная правка |
| Тайм-слоты лиловыми pill | Слоты брони красить `--color-soft`-пастелью с тёмным текстом |
| Статусы текстом на нейтральном чипе, без красного/зелёного | Статусы брони (ожидание/подтверждено) делать нейтральными чипами с иконкой |
| Цвет дают фотографии, UI монохромный | Фото натуральные (уже принято), вокруг — минимум краски |

**Суть в одном предложении:** нейтральный почти-монохром + один пастельный акцент двумя тонами, фото-первые карточки с наложенным display-названием и glass-чипами, полные pill-формы с большими радиусами, никаких рамок и теней — весь характер несут фотографии и шрифт.
